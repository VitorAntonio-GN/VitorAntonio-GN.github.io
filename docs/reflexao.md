# Reflexão sobre o aprendizado

O desenvolvimento deste portfólio foi uma oportunidade de colocar em prática conhecimentos adquiridos ao longo dos estudos de Engenharia da Computação, além de explorar novas ferramentas e conceitos relacionados ao desenvolvimento web.

Durante o projeto, pude aprofundar meus conhecimentos em HTML e CSS, trabalhando com estruturação semântica, organização de estilos, responsividade e acessibilidade. Também utilizei JavaScript para implementar funcionalidades dinâmicas, como o carregamento de repositórios por meio da API do GitHub, a filtragem de projetos por linguagem de programação e a leitura de cursos e certificações armazenados em um arquivo JSON.

Uma das principais dificuldades foi organizar o código e dividir as funcionalidades em partes menores, mantendo uma estrutura que facilitasse a manutenção e futuras modificações. Esse processo contribuiu para compreender melhor a importância da separação de responsabilidades e da criação de funções específicas para cada tarefa.

Outro aspecto importante foi a utilização de Git e GitHub durante todo o desenvolvimento. Pude colocar em prática conceitos como versionamento de código, Conventional Commits, branches, Issues e Pull Requests. Organizar o trabalho dessa maneira permitiu acompanhar a evolução do projeto, registrar cada etapa e compreender melhor um fluxo de desenvolvimento utilizado em equipes de software.

Também percebi a importância de pensar na experiência de quem utiliza o sistema. Questões como adaptação a diferentes tamanhos de tela, mensagens de carregamento e erro, navegação por teclado e preferência por movimento reduzido passaram a fazer parte das decisões durante a implementação.

Ao final, considero que o desenvolvimento do portfólio foi uma experiência importante para consolidar conhecimentos teóricos por meio de uma aplicação prática. Além de resultar em um espaço para apresentar minha trajetória acadêmica e meus projetos, o trabalho proporcionou mais familiaridade com ferramentas e práticas que pretendo utilizar em projetos futuros e na minha formação profissional.
